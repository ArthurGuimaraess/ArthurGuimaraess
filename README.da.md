## Udvalgt projekt

### ✳ [NORA — En mere omsorgsfuld digital følgesvend i hverdagen](https://github.com/ArthurGuimaraess/nora-personal-assistant)

NORA er et fælles projekt udviklet af dets grundlæggerteam. Formålet er at undersøge mere tilgængelige og fleksible måder at støtte daglige rutiner, fokus, hvile og personlig organisering på.

Produktretningen tager højde for erfaringer hos mennesker, der lever med depression, angst, ADHD, OCD, søvnløshed og andre udfordringer relateret til mental sundhed, neuroudvikling, søvn eller daglige rutiner. NORA præsenteres ikke som et diagnose- eller behandlingsværktøj.

**Produktretning:** Trivsel · Neurodiversitet · Søvn · Tilgængelighed · Personlig organisering

**Teknologier:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · REST-API'er · Java · Android Studio · Gradle · Pytest

➡️ **[Se NORA-repositoriet](https://github.com/ArthurGuimaraess/nora-personal-assistant)**
