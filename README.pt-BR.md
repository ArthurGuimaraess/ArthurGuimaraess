## Projeto em destaque

### ✳ [NORA — Uma companhia digital mais acolhedora para o cotidiano](https://github.com/ArthurGuimaraess/nora-personal-assistant)

A NORA é um projeto colaborativo desenvolvido por sua equipe fundadora. Seu propósito é explorar formas mais acessíveis e adaptáveis de apoiar rotinas, foco, descanso e organização pessoal.

A direção do produto considera experiências de pessoas que convivem com depressão, ansiedade, TDAH, TOC, insônia e outros desafios relacionados à saúde mental, neurodesenvolvimento, sono e rotina — sem apresentar o produto como ferramenta de diagnóstico ou tratamento.

**Direção do produto:** Bem-estar · Neurodiversidade · Sono · Acessibilidade · Organização pessoal

**Tecnologias:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · APIs REST · Java · Android Studio · Gradle · Pytest

➡️ **[Conheça o repositório da NORA](https://github.com/ArthurGuimaraess/nora-personal-assistant)**
