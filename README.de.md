## Ausgewähltes Projekt

### ✳ [NORA — Ein einfühlsamer digitaler Begleiter für den Alltag](https://github.com/ArthurGuimaraess/nora-personal-assistant)

NORA ist ein gemeinschaftliches Projekt des Gründungsteams. Ziel ist es, zugänglichere und flexiblere Möglichkeiten zur Unterstützung von Alltagsroutinen, Konzentration, Erholung und persönlicher Organisation zu erkunden.

Die Produktidee berücksichtigt die Erfahrungen von Menschen mit Depressionen, Angstzuständen, ADHS, Zwangsstörungen, Schlaflosigkeit und anderen Herausforderungen im Zusammenhang mit psychischer Gesundheit, Neuroentwicklung, Schlaf oder Alltag. NORA wird dabei nicht als Diagnose- oder Behandlungsinstrument dargestellt.

**Produktfokus:** Wohlbefinden · Neurodiversität · Schlaf · Barrierefreiheit · Persönliche Organisation

**Technologien:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · REST-APIs · Java · Android Studio · Gradle · Pytest

➡️ **[NORA-Repository ansehen](https://github.com/ArthurGuimaraess/nora-personal-assistant)**

## Technologien und Arbeitsbereiche
