## Wyróżniony projekt

### ✳ [NORA — Bardziej przyjazny cyfrowy towarzysz na co dzień](https://github.com/ArthurGuimaraess/nora-personal-assistant)

NORA to wspólny projekt tworzony przez zespół założycielski. Jego celem jest badanie bardziej dostępnych i elastycznych sposobów wspierania codziennych nawyków, koncentracji, odpoczynku i organizacji osobistej.

Kierunek rozwoju produktu uwzględnia doświadczenia osób żyjących z depresją, lękiem, ADHD, OCD, bezsennością i innymi wyzwaniami związanymi ze zdrowiem psychicznym, neurorozwojem, snem lub codziennymi rutynami. NORA nie jest przedstawiana jako narzędzie diagnostyczne ani terapeutyczne.

**Kierunek produktu:** Dobrostan · Neuroróżnorodność · Sen · Dostępność · Organizacja osobista

**Technologie:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · REST API · Java · Android Studio · Gradle · Pytest

➡️ **[Zobacz repozytorium NORA](https://github.com/ArthurGuimaraess/nora-personal-assistant)**

## Technologie i obszary pracy

- **Backend:** Python, FastAPI, REST API i SQLite
- **Frontend:** JavaScript, HTML i CSS

- **Jakość i workflow:** Pytest, debugowanie, Git, GitHub i Markdown
- **Poznawane integracje:** Google Gemini API i SerpAPI (opcjonalnie, po stronie serwera)
