## Главный проект

### ✳ [NORA — Более бережный цифровой помощник на каждый день](https://github.com/ArthurGuimaraess/nora-personal-assistant)

NORA — совместный проект команды основателей. Его цель — исследовать более доступные и гибкие способы поддержки повседневных привычек, концентрации, отдыха и личной организации.

В концепции учитывается опыт людей, сталкивающихся с депрессией, тревожностью, СДВГ, ОКР, бессонницей и другими трудностями, связанными с психическим здоровьем, нейроразвитием, сном и повседневной жизнью. NORA не позиционируется как средство диагностики или лечения.

**Направления продукта:** благополучие · нейроразнообразие · сон · доступность · личная организация

**Технологии:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · REST API · Java · Android Studio · Gradle · Pytest

➡️ **[Открыть репозиторий NORA](https://github.com/ArthurGuimaraess/nora-personal-assistant)**

## Технологии и направления работы

- **Backend:** Python, FastAPI, REST API, SQLite
- **Frontend:** JavaScript, HTML, CSS
- **Мобильный прототип:** Java, Android Studio, Gradle, WebView
- **Качество и инструменты:** Pytest, отладка, Git, GitHub, Markdown
- **Изученные интеграции:** Google Gemini API и SerpAPI (опционально, на стороне сервера)
