## Proyecto destacado

### ✳ [NORA — Una compañera digital más amable para el día a día](https://github.com/ArthurGuimaraess/nora-personal-assistant)

NORA es un proyecto colaborativo creado por su equipo fundador. Su objetivo es explorar formas más accesibles y adaptables de apoyar las rutinas diarias, la concentración, el descanso y la organización personal.

La visión del producto tiene en cuenta las experiencias de personas que viven con depresión, ansiedad, TDAH, TOC, insomnio y otros desafíos relacionados con la salud mental, el neurodesarrollo, el sueño o las rutinas. NORA no se presenta como una herramienta de diagnóstico o tratamiento.

**Enfoque del producto:** Bienestar · Neurodiversidad · Sueño · Accesibilidad · Organización personal

**Tecnologías:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · APIs REST · Java · Android Studio · Gradle · Pytest

➡️ **[Explorar el repositorio de NORA](https://github.com/ArthurGuimaraess/nora-personal-assistant)**
