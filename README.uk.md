## Основний проєкт

### ✳ [NORA — Дбайливіший цифровий помічник для повсякденного життя](https://github.com/ArthurGuimaraess/nora-personal-assistant)

NORA — спільний проєкт команди засновників. Його мета — досліджувати доступніші та гнучкіші способи підтримки повсякденних звичок, концентрації, відпочинку й особистої організації.

Під час розробки враховується досвід людей, які живуть із депресією, тривожністю, СДУГ, ОКР, безсонням та іншими труднощами, пов'язаними з психічним здоров'ям, нейророзвитком, сном або щоденними звичками. NORA не позиціонується як засіб діагностики чи лікування.

**Напрям продукту:** Добробут · Нейрорізноманіття · Сон · Доступність · Особиста організація

**Технології:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · REST API · Java · Android Studio · Gradle · Pytest

➡️ **[Переглянути репозиторій NORA](https://github.com/ArthurGuimaraess/nora-personal-assistant)**

## Технології та напрями роботи

- **Backend:** Python, FastAPI, REST API та SQLite
- **Frontend:** JavaScript, HTML і CSS
- **Мобільний прототип:** Java, Android Studio, Gradle і WebView
- **Якість і робочий процес:** Pytest, налагодження, Git, GitHub і Markdown
- **Досліджені інтеграції:** Google Gemini API та SerpAPI (необов'язкові, на стороні сервера)
