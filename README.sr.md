## Istaknuti projekat

### ✳ [NORA — Nježniji digitalni saputnik za svakodnevni život](https://github.com/ArthurGuimaraess/nora-personal-assistant)

NORA je zajednički projekat koji razvija osnivački tim. Cilj je istražiti pristupačnije i prilagodljivije načine podrške svakodnevnim rutinama, fokusu, odmoru i ličnoj organizaciji.

Smer proizvoda uzima u obzir iskustva osoba koje žive s depresijom, anksioznošću, ADHD-om, OKP-om, nesanicom i drugim izazovima povezanim s mentalnim zdravljem, neurorazvojem, snom ili svakodnevnim rutinama. NORA se ne predstavlja kao alat za dijagnostiku ili lečenje.

**Smer proizvoda:** Dobrobit · Neurodiverzitet · San · Pristupačnost · Lična organizacija

**Tehnologije:** Python · FastAPI · JavaScript · HTML/CSS · SQLite · REST API-ji · Java · Android Studio · Gradle · Pytest

➡️ **[Pogledaj NORA repozitorij](https://github.com/ArthurGuimaraess/nora-personal-assistant)**
